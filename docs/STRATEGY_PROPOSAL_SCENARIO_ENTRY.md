# 场景化候选与分层触发：策略方案（交易接入尚未实施或上线）

本地已实现独立的影子候选、监测和回放，不接管生产决策或下单。实现边界、负收益回放结果及后续验证要求见 `docs/SCENARIO_SHADOW_RESEARCH.md`。

## 目标
接受可承受、可解释的不确定性，减少符合预先定义条件的机会被遗漏；不要求100%把握，不以增加订单数量为目标，也不承诺抓住每一波行情。

此前简化机械方案在检验段均亏损，因此本方案不是直接部署“更快的5分钟突破”，也不是把失败实验换一个名字上线。需要先按以下不同职责重构研究设计，再独立验证。

## 一、硬约束与软判断分离

不可放宽的硬约束：交易环境支持、真实数据与时点、账户/持仓/挂单一致性、实际可用资金、止损保护、最小数量、价格几何、净成本后风险收益、单笔及组合风险、持久化授权有效期与幂等。

不能一票否决所有场景的软信号：单个RSI超买/超卖、短周期动量为负、低ADX、4H处于区间、成交量暂时缩减、多个派生指标不一致。它们要解释所选形态的支持与反证，而不是叠成“所有指标都完美才下单”。

当前未校准confidence也不应被解释为胜率。方案实施前要清点真实启用的拦截器，区分风控事实和研究偏好，不暗中删除安全门禁或强迫模型填写高分。

## 二、不同周期各做一件事

- **4H：识别市场环境和适合研究的形态。** 趋势、区间、过渡状态，不要求每次都新翻多/翻空。
- **1H：识别结构、关键价格与失效边界。** 区分健康回踩和真正破坏趋势，不要求所有动量指标同时翻正。
- **5M：确认入场时点。** 只使用已收盘数据；检查局部结构触发，不用未收盘K线制造提前信号。

典型例子：4H多头、1H正在回调，本身并不矛盾。只要1H关键结构未失效，5M形成预先规定的回踩结束触发，就可以研究首笔风险受控的入场，而不必再等1H速度也完全转正。

## 三、按场景定义准入，不用一套规则否决所有市场

| 场景 | 预先建立的候选 | 触发 | 失效 |
|---|---|---|---|
| 趋势回踩 | 趋势环境仍在，1H关键结构未破，价格进入有依据的回踩区域 | 5M局部摆动结构恢复，如收盘突破已确认的短线摆动高点；做空镜像 | 回踩结构低点/高点失效或成本后空间消失 |
| 区间突破 | 明确区间边界，已比较真实突破与假突破反证 | 5M收盘突破边界，或突破后回测守住；无需等待整根4H形态变化 | 回到区间、回测失守或追价超过上限 |
| 区间边界反转 | 明确区间上下沿，而非区间中间随意猜方向 | 边界处出现可核验的局部反转与可定义止损 | 区间边界有效破坏 |

先验证趋势回踩和突破，区间反转单列实验；在强趋势中不自动启动逆势摸顶抄底。

目标价来自可解释的结构/策略假设，不因不够净R:R而扩大；止损来自失效条件，不为了凑盈亏比而贴得不合理地近。

## 四、候选提前准备，触发后才申请交易

建议研究状态机：

`无形态 → 候选已建立 → 等待明确触发 → 触发后复核 → 挂单待成交 → 持仓管理`

另设“结构失效”“硬门禁拒绝”“审计不完整”，不把这些都混成WAIT。

- 候选阶段已经确定方向、价格区间、失效条件、反证和过期时间；不必等完美时点才开始研究。
- 每个新5M收盘检查既有条件；不能每轮从零构思、不断移动目标。
- 研究计划可以保留约30～60分钟作为待验证起点，但**交易授权仍必须符合现有新鲜度与5分钟有效期**。触发后用当前快照复核/重新签发，不能拿30分钟前的模型指令下单。
- LLM负责有证据的候选审查与解释，不是“觉得风险大就无限否决”。是否取消其执行否决权需作为独立实验，不能直接让尚未验证的机械规则绕过它。
- 当前假设已成立、仅等价格成交，才允许普通限价单；若还需要未来止跌、放量或动量确认，只是研究计划，不能把触价冒充确认完成。
- 挂单提交后跟踪成交、部分成交、过期与结构变化，不为了“本轮有动作”反复撤单重挂。

## 五、承认不确定性，但用风险预算控制，而非用杠杆补偿

可以验证分段建仓：首笔只使用一部分单笔风险预算，后续结构确认后才允许剩余部分，并维持总预算不增加。

例如300U资金池、单笔计划风险上限1.5U时，可把0.9U/0.6U作为待测试的分配方式，而不是两笔各1.5U。仅允许同向、盈利/结构支持的加仓，不摊平亏损、不放宽止损。最小张数不允许合理拆分时，不硬凑订单、不扩大预算。

上述比例只是实验起点，不是已优化的参数或最大亏损保证；本轮不启用该建仓方式、不改杠杆。

## 六、WAIT审计是透明性，不是额外堆门槛

- WAIT要解释哪些具体前提未满足，以及条件变化后怎么重审。
- “已有仓位”不是天然禁止同向加仓；必须准确区分亏损、反向冲突、加仓次数、资金/保证金等真实约束。
- 完善可引用的持仓约束事实，避免模型选错`position_constraint`类别就长期循环不完整。
- 审计通过不证明等待具有收益优势。审计不完整也不能转成开仓，应定位缺失/矛盾字段，必要时仅做一次有界的推理修复；不复用过期指令，不重试交易写操作。

## 七、如何判断方案更好

“机会”必须按当时已知信息和预先声明的形态/触发定义，不能回头看到涨了就认定此前任何价位都应买入。

对比：
1. 有效候选覆盖与触发延迟；
2. 哪一层阻止入场，理由是否成立；
3. 假突破/触发后立即失效比例；
4. 限价成交率、撤单率、实际滑点；
5. 扣成本后的R分布、盯市收益、最大回撤及资金费；
6. 不同市场阶段、标的与时间段是否稳健。

先离线因果回放，再前向影子运行，再决定是否进入模拟执行。未通过验证不推广；不能靠多次试参数直到挑出一条好看的曲线。这里提出的是设计方案，不是收益证明，也未修改现有线上入场逻辑。
