# 账户配置界面整合与等待诊断（2026-09-07）

## 本地修复

- 概览原先读取`credentials.okx_configured/simulated_trading`，而运行概览返回`okx/llm`，导致已配置Key被误显示为未配置。现在后端提供兼容字段及统一连接摘要，前端同时兼容旧响应；账户管理链接指向账户中心。
- 三个用途下拉框默认显示实际绑定。刷新时同步已经保存的绑定，不覆盖用户尚未提交的选择；选择无变化不再允许重复保存。后端同绑定请求也是无副作用的幂等操作，不清理决策、不更换绑定版本。
- 账户卡片展示API Key首尾脱敏值；Secret和Passphrase仅返回已保存布尔状态，不返回明文或片段。配置文件中的旧凭据以只读脱敏视图提供，明确当前生效连接仍以上方用途绑定为准。
- 原自动生成名称中的“待核验”后缀在展示层规范化；真实核验状态另列，不修改用户自定义名称或服务器绑定。
- 后台手动平仓权限移至账户中心。修改需明确确认，只设置原有`OKXQUANT_MANUAL_CLOSE_ENABLED`，不执行平仓、不改账户绑定，也不关闭独立持仓保护。
- CLI检测/安装维护入口移至账户中心，仍要求原确认与超级管理员权限。
- 原“交易账户与标的”改为“交易标的与持仓”，删除旧环境、Key与全局OAuth编辑表单，保留本金基准、标的管理、持仓读取及受保护的手动平仓。旧配置API暂留兼容，不提供第二套编辑UI。

## 资讯调度

当前网关`JOBS`定义新闻任务间隔600秒。账户中心显示同一调度常量，而不是独立维护另一个周期。服务器最近自动任务记录为16:19、16:29、16:39，符合约每10分钟尝试一次。人工读取可以提前更新；接口成功读取时间不同于新闻发布时间，失败不会推进最近成功时间。
