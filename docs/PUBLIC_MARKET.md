# 公共行情采集与 CPU 隔离

## 边界

`scripts/public_market.py` 是公共行情读取通道：仅允许固定的 OKX 公共 GET 路径，以及计算指标的 `/api/v5/aigc/mcp/indicators` 只读 POST。不能请求账户、下单、撤单、止损或平仓端点，不签名、不发送 API Key/Secret/Passphrase。

- 原生 REST 行情保留原有公共市场来源。
- 指标沿用已部署 OKX CLI 1.4.5 的服务、默认参数和 DEMO/LIVE 数据源标记，不在本地重写近似算法。DEMO/LIVE 指标缓存隔离（模拟盘标记不是鉴权凭据）。
- 后端原来带模拟盘标记的公共读请求仍保留该标记，缓存同样隔离。
- Smart Money 是**需要鉴权的只读接口**，不混入公共 HTTP 通道。保留 CLI，显式绑定冻结/当前环境，凭据只走进程环境，不出现在命令参数中；不改变交易写通道。

## 消除重复进程与请求

每轮因子采集的 6 个订单簿 CLI 改为直接公共 REST。每标的 ADX、KDJ、BBWidth、CMF 四次 CLI 改为一次批量指标请求。ADX `[14]`、KDJ `[9,3,3]`、BBWIDTH `[20,2]`、CMF `[20]`，均保持 `returnList=false`。

原来的每轮 **31 个 Node CLI**，变为公共采集 **0 个 Node**，另有 Smart Money 缓存未命中时最多 **1 个**。不承诺整个应用不再使用 Node：私有交易操作、其他未涉及的业务仍使用既有 CLI。

交易前 ADX 与因子刷新共享相同指标缓存；K 线按标的、周期、市场来源共用最多最近 100 条数据，再为不同调用者截取原先要求的 16/24/25/35/45 条，保持顺序、窗口和计算输入不变。大于 100 条的明确请求独立缓存，不擅自分页或扩展到 300 条以上。

## 并发、新鲜度与失败语义

共享目录位于 `data/.public-market`（Docker 数据卷）：

- OS `flock` 提供跨进程、跨线程 single-flight 和并发门禁；不是仅用进程内线程锁。进程退出后由操作系统释放。
- 公共 HTTP 总并发最多 **3**；按接口另外限制发送间隔。仅 Smart Money CLI 使用独立的单进程门禁；下单、撤单、止损不等待这些采集锁。
- 单次公共调用有包括排队、限频、网络在内的超时预算。因子整轮最多 45 秒，低于调度任务 55 秒预算。
- Ticker / Orderbook 缓存 2 秒；K 线 5 秒；指标、资金费率、OI、统计数据 10 秒；合约信息 30 秒。
- K 线和指标缓存不会跨越对应周期边界；公共数据缓存按参数和模拟/真实市场来源分开。
- Smart Money 缓存 30 秒，并按完整凭据指纹与币种集合隔离；凭据轮换改变缓存键。无法可靠识别 OAuth 账户时不复用该缓存。
- 因子刷新有独立跨进程互斥锁。仅相同标的配置、相同账户指纹、完整成功且刷新开始不足 10 秒、公共源数据年龄不足 20 秒的快照可复用；保留原时间戳，不把旧数据重新标成新数据。
- 网络失败、空公共结果、业务错误、缺失指标不写成功缓存；单项缺失不会丢弃同批其余可用指标；过期缓存**不会**作为失败回退。K 线失败不再回退启动 Node。
- 因子 `collection_quality` / `data_status` 标注部分失败；部分结果不会作为完整新鲜快照复用。
- 缓存使用唯一临时文件原子替换，避免不同进程写同一个 `.tmp`。

## 验证

新增离线测试覆盖：实际 Linux 多进程去重与并发上限、线程互斥、超时预算、TTL/时间回拨、周期边界、无过期回退、部分指标失败、DEMO/LIVE 数据源隔离、凭据轮换、无鉴权公共请求、私有端点拒绝、因子刷新合并及原时间戳保留。

2026-09-06 在服务器使用固定历史时间点 `1788652799999`，将批量 HTTP 与原 CLI 四次单指标请求对比：四项指标的时间戳及值均完全一致。检查中确认指标服务的模拟盘标记会影响结果，因此不是把所有公共请求一律强制为真实盘数据。

原交易管理函数（下单、撤单、持仓保护、止损、执行锁）不在本次替换范围；仍要求新鲜 AI 决策，不因行情缓存而复用旧交易指令。
