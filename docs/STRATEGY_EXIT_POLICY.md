# 程序目标价与统一退出规则

## 适用范围

这是执行逻辑一致性修复，不是收益验证，也不保证减少所有 WAIT。
未修改风险预算、杠杆上限、账户绑定、自动交易开关；未恢复已移除的置信度开仓门槛。
所有开仓仍需要模型选择、契约校验、实时触发复查和最终账户风险核验。

## 1. 程序目标价必须有观察依据

`closed-candle-plans-v2` 保留 8 根 15M K 线的突破窗口，以及不小于 1.5 ATR 的初始止损距离。
目标价回归此前 12 根已收盘小时 K 线的通道边界，不再用 `3 × 止损距离` 自动推远目标价。

每个候选携带 `target_observation`：时间框架、价格字段、窗口起止收盘时间、目标价格及 `extrapolated=false`。
空间不足时保留实际价格与成本后盈亏比的拒绝证据。突破延伸目标不能只为凑够盈亏比而产生；如要引入，须单独定义和验证。
版本及候选 ID 会改变，旧 ID 不得授权新版本订单。不会追溯修改旧决策或现有订单的止盈止损。

## 2. 同一预设、同一 ATR、同一浮盈启动条件

预设定义位于 `scripts/exit_policy.py`，当前版本为 `position-exits-v1`。
以下参数是工程规则，不是经过校准的获利概率，也不等价于“保证持有到某个 R”。

| 参数 | standard | small300 |
| --- | ---: | ---: |
| 时间退出持有时长门槛 | 6h | 4h |
| 时间退出价格浮盈上界 | 0.15 ATR | 0.10 ATR |
| 一级浮盈保护启动 | 2.5 ATR | 1.8 ATR |
| 二级锁利启动 | 4 ATR | 3 ATR |
| 一级保留收益下限 | 0.5 ATR | 0.3 ATR |
| 二级保留收益下限 | 1.5 ATR | 1 ATR |
| 动能退出峰值门槛 | 2.5 ATR | 1.8 ATR |
| 动能退出回撤距离 | 1.2 ATR | 0.8 ATR |

- 动态退出优先使用采集得到的 `atr_15m`，缺失时使用有效 `atr` 并明确记录来源；不再混用多个 ATR 或额外注入价格百分比下限。
- 一级启动距离为 `max(预设一级 ATR 门槛, 估算往返成本 × 1.5)`，不再由 `0.8R` 取较小值提前启动。
- 成本保护、收益保留比例、阶梯下限在同一个启动条件后合并计算；取更有保护性的止损，不得放宽已有止损。
- 动能退出同时满足同一成本门槛与预设峰值、回撤条件。
- AI 的 `UPDATE_SL` 止盈改单也必须满足同一预设启动条件、成本覆盖和行情缓冲。它只使用持仓状态中最近 300 秒内的 ATR 观察；数据缺失或过期时不发送改单，原云端保护保留。
- 硬止损、云端 OCO 核验失败后的安全退出，以及既有独立 AI 平仓校验，不等待上述盈利条件。
- 已收紧的历史止损照常生效，不能为“让盈利奔跑”而放宽或重置。

## 3. 预设读取异常的处理

每个持仓的 `exitPolicy` 保存最近一次成功核验的预设 ID、策略版本与执行签名，通过现有 `position_trackers.json` 持久化。

1. 成功读取：采用当前明确激活的预设，更新已核验快照。
2. 读取失败且存在同版本有效快照：沿用最近核验的预设，标记 `last_verified`。
3. 没有有效快照：使用 `conservative_fallback`，采用现有预设中较早的启动/时间/回撤门槛及较高的保护下限；不冒充 standard 或 small300。

降级状态写入 `exitPolicyStatus`，首次进入或状态改变时输出告警，重复异常不持续刷屏。
降级不覆盖已核验快照；读取恢复后重新标记 `active_profile`。不打印异常中的配置正文或凭证。
硬止损、云端保护持续运行；新开仓风险核验不会因为这层持仓降级而绕过。

## 4. 退出说明与证据

时间退出的条件是：持仓时间严格超过所选门槛，并且有符号价格浮盈低于所选 ATR 上界。
它可能覆盖亏损或小幅盈利，不应统称“无波动横盘”。

巡检说明与交易记录备注使用同一个生成字符串，例如：

```text
预设 small300：持仓 4.02h > 4h，价格浮盈 -0.200 ATR < 0.1 ATR，时间退出
```

`exit_evidence` 附带预设及来源、实际时长、时长门槛、价格浮盈、ATR 数值/来源/观察时间与触发阈值。
未获平仓确认时保留持仓追踪及 `lastExitAttempt`，不记录成成功平仓，也不增加盲目重试。
日志中的浮盈不是最终结算净盈亏，实际结算仍以交易所回执和账本为准。

## 5. 回归验证

使用仓库隔离测试入口运行：

```bash
python scripts/run_tests.py
```

覆盖目标价不可补远、多空对称的预设启动、成本门槛、旧止损保留、动态回撤退出、预设异常/重启恢复、精确时间退出说明、平仓失败保留状态以及 AI 改单的新鲜度和单调收紧规则。
测试在一次性源码副本中执行，阻止网络和外部命令，不加载真实运行凭证或触发交易任务。
