# 成交执行与证据修复（2026-09-16）

## 杠杆

标准风控、small300 都只保留原有档位。新增独立风险字段 scalp_max_leverage（默认20），
不再由波段的 max_leverage=5 覆盖模拟盘短线上限。短线未指定建议值时默认10倍，
明确建议可在上限内使用20倍；不是每笔强制20倍。波段默认3倍、最高5倍。

仅模拟盘无持仓、无未完成委托的标的允许自动设置杠杆。设置前记账，最多写一次，
然后读回确认；超时不重复写。持仓中的标的不改杠杆，实盘仍沿用交易所实际杠杆及原上限。
风控按止损距离、手续费、组合风险计算数量，不按杠杆比例放大已有风险预算。
设置耗时后重新核对候选有效期、持仓和行情，未确认则不提交新开仓。

## 部分成交与保护

此前部分成交1390张、随后补齐2536张的过程中，保护程序两次读不到OCO便整仓退出。
现在仅对账户隔离、生命周期匹配、最近90秒内的本系统入场给予本次调用内最多12秒、
10次只读检查；不跨周期无限宽限。允许同一入场内数量增长至已记录计划上限，
保护覆盖按最新实际数量核验。已到止损、缺价、外部持仓或其他生命周期不享受宽限。
到期仍不能证明覆盖时，安全退出仍保留；不是取消止损或无保护持仓。

## 平仓与归因

具备静态凭据及完整持仓身份的执行使用带clOrdId的只减仓市价单：
先撤销剩余委托并确认，再读持仓的posId+cTime与实际数量，最后提交一次。
确认记录保存ordId、原观测量、实际平仓请求量与退出前持仓快照。
不确定响应只读订单和持仓，不重复发市价平仓单。旧CLI兼容路径仍保留。

历史CLI整仓平仓只有在同账户、同生命周期、同方向、唯一完整平仓成交及全量数量
相互印证时才归类为“执行记录关联”，绝不伪装为直接订单ID证据。

## 证据与统计

完整性包括策略可复现版本、setup、周期、决策/候选/开仓订单/成交、开仓特征、
新闻快照、退出归因、平仓订单、退出前行情及费用。缺项列入evidence_gaps。
旧local版本和缺失过程快照如实标为partial，不回填猜测数据。
若决策周期与实际执行周期冲突，以执行记录展示，保留两值及冲突标记。

每轮持仓守护记录账户/生命周期隔离的position_observation。最大浮盈浮亏只是
周期采样极值，不是假称逐笔tick真实最高最低。历史未采集的数据保持空值。

horizon_stats.json 保留scalp/swing/unknown及by_strategy，新增by_version、by_loss_class
和pending_settlements。待结算不再算成零盈亏/失败；真正零盈亏单列breakeven。
亏损分为策略/市场、成本、保护性执行退出、退出来源未确认。所有类别仍计入总损益，
不通过移除失败交易美化成绩。此修复不是策略盈利认证，也没有反转入场方向。
