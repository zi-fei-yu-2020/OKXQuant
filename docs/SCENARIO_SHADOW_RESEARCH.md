# 场景候选与分层监测：本地影子实现

## 实施边界

已实现候选引擎、独立监测、持久化证据、离线回放及前后台可选展示。**没有接管生产模型决策、没有自动下单、没有修改服务器部署或任务调度。** 资金池仍默认关闭，杠杆、最终风险预算与独立持仓保护均未调整。

“触发”仅是一个待复核的研究事件，不是订单。未来是否接入LLM复核和交易执行，必须单独验证、授权；当前并未实现自动消费这些复核请求的交易程序。

## 实现

### 纯候选引擎 `scripts/scenario_entry.py`

- 4H已收盘数据判断方向环境；1H定义结构；5M已收盘数据触发。
- 实验形态为趋势回踩和区间突破。1H动量暂时逆向不自动否决趋势回踩。
- 使用固定窗口与固定参数，候选创建时冻结触发位、结构失效位、目标位、45分钟有效期及证据摘要；候选定义有哈希校验。
- 已武装的候选不随新指标重新移动触发价、止损、目标或过期时间。同标的/方向/场景/小时锚点只产生一次假设，避免不断重建。
- 创建当根不能触发；只在后续闭合5M收盘跨越冻结触发位时申请新复核。
- 同根同时越过止损与触发时，先认定结构失效；宏观环境失效、超时、追价过远及触发后成本净盈亏比不足时均明确记录。
- 数据缺失不填零；K线未收盘、未来数据、连续性缺口、跨周期同一收盘价不一致均不产生触发。监测恢复后不补发已错过的历史触发。
- 模型复核请求的研究有效窗口为5分钟，不是延长已有交易授权。

具体实验定义：趋势回踩的结构失效位来自前6根已收盘1H极值，目标来自前12根1H极值，触发来自前3根5M极值；突破使用前12根5M区间、前3根5M局部失效位和一个冻结区间宽度的目标投影。后者是待检验假设，不是观测到的未来流动性。不为凑盈亏比放大目标。

### 独立监测 `scripts/scenario_shadow.py`

- 无配置/未启用时不访问网络，也不创建数据库。
- 必须显式选择shadow_only及公共网络许可；没有模型调用、账户接口、凭据读取、Node CLI或交易写操作。
- 复用公共行情读取器的缓存、限频和跨进程并发控制；每个5M周期最多尝试一次，429或其他失败无重试。
- 同一周期共用数据，1H/4H缓存只在各自新的闭合边界更新；5M检查不重复调用整套LLM或因子计算。
- 每次采集轮总预算20秒、单次请求最多3秒，最多6标的。环境支持未知或不允许时不读取该标的K线。
- 默认示例读取既有本地环境目录缓存，不启动支持目录刷新线程。目录过期/不可用时仅观察，不根据公共价格猜测模拟盘支持。
- SQLite事务将状态与事件一起落盘；重复或并发运行不重复发布触发。scope绑定环境、标的集合及参数，不能复用模拟盘缓存作为实盘缓存。
- 前台及管理员页面只读状态；未启用时隐藏。已过期的复核窗口不会继续展示成当前待入场许可。

## 本地使用（没有替用户启用）

复制并审查 `docs/scenario_shadow.example.json`，将scope设为当前账户隔离标识。若需要前后台显示，监测scope必须与该页面选中的账户一致。示例默认enabled=false，不包含凭据。

```bash
# Linux/WSL；仅在明确启用研究配置之后运行。不会添加cron或修改现有调度。
python scripts/scenario_shadow.py --config /path/to/research-config.json --once --allow-public-network
```

可由独立的每分钟任务调用，程序只消费新的5M闭合边界，并预留5秒收盘确认缓冲。未部署/未配置此任务时，不会自动运行。支持缓存由原系统维护；缓存不可用时不会偷偷切到实盘或放行。

```bash
# 冻结快照诊断：纯离线
python scripts/wait_diagnostics.py --input logs/WAIT_LATEST_20260907.json --output logs/WAIT_DIAGNOSIS_20260907.json
# 已有30天数据的回顾性诊断，不是独立新样本
python scripts/scenario_replay.py --input logs/entry-study-20260907/dataset.json --output logs/scenario-study-20260907/replay-30d.json
```

## 验证结果及限制

### 与16轮等待对应的窗口

另补采9:00至12:30的已收盘公共5M K线和资金费记录，共5标的各42根K线，仅10个公共读取请求，没有读取账户或发送交易。冻结窗口08:40之后至12:30的反事实回放：5个候选通过初始研究门槛，其中2个触发、3个失效；另有40个方案未通过初始结构/净盈亏比检查。

两个研究触发是12:20的DOGE和SUI趋势回踩。它们不是历史生产LLM已经认可的订单，也没有证明有资格通过当时账户风控，更不能据此断言能够盈利。该窗口空仓起步；未模拟该账户当时的实际仓位。

### 已使用过的30天历史数据

- 235个候选通过初始研究门槛、67个研究触发；大量方案仍被初始净盈亏比门槛拒绝，保留拒绝证据，不降低门槛粉饰结果。
- 趋势回踩独立实验：65个研究触发，50条已关闭回测交易，含期末盯市收益约-1.074%，最大回撤约4.743%。
- 区间突破独立实验：2个研究触发，2条已关闭回测交易，收益约-0.499%，最大回撤约0.751%。
- 两个场景分别测试，没有组合后选优。研究起点5000U、3倍，复用现有成本和风险规则；不是300U实盘配置建议。

这些数据之前已被查看过，**不是新的独立样本外验证**。回放不包括生产LLM判断/调用成本，不证明历史模拟盘支持和账户可用额度。触发不等于成交，研究适配器最早下一根K线执行限价，使用一根5M有效期和现有保守费用/止损路径。

**当前不批准自动推广。** 新机制能够生成可追踪候选，但没有证据声称已经解决策略盈利或所有漏行情问题。

### 实时前向状态

WSL中一次真实公共接口采集试跑在连接OKX时超时。没有修改网络策略、没有增加重试，也没有把它算作前向验证通过。已有公共数据回放与模拟网络边界测试不等于持续实时观察。后续仍需恢复本地研究采集链路，并收集真正未看过的前向样本。
