# 300U可选策略资金池

## 不是交易所隔离钱包
这是新增风险的**软件预算上限**，不是资金划转、子账户创建或最大亏损承诺。现有执行仍为全仓合约，极端跳空、清算、账户混用或外部人工交易可能影响池外权益。实盘需要用户自行确认合法可用的账户产品、可承受风险及独立账户安排。本功能不设置杠杆、不切换DEMO/LIVE。

代码默认关闭。示例 `docs/capital_pool.300.example.json` 不会自动复制到运行目录，也不代表已验证的最优资金参数。

## 配置与启用边界
读取 `data/capital_pool.json`，字段严格校验，未知字段或错误布尔类型会阻止新风险。

- `enabled`：默认false。
- `environment`：与实际账户环境必须一致；demo配置不能自动迁移到live。
- `allocation_id`、`budget_usdt`：额度身份与上限，首次初始化后不能通过更改它们清空亏损。
- `max_active_instruments=2`：持仓与未成交入场挂单合计最多2个标的。不是额外允许2笔挂单。
- `single_asset_margin_fraction=0.2`：单标的保证金上限为风控基数的20%，同时不能超过原风险政策的绝对上限。
- `total_margin_fraction=0.5`：组合保证金预留不超过风控基数的50%。原有可用保证金保留比例仍适用，因此实际可提交额度可能更低。
- `dedicated_account_confirmed`、`virtual_cap_acknowledged`：启用前必须显式确认专属策略账户归属及虚拟额度不隔离资金的风险。
- `allow_live`：默认false。实盘还需要单独显式允许；此字段不会更改交易环境或安装凭据。

**不要直接在有持仓或入场挂单的账户上初始化。** 独立持仓保护照常运行；账户平仓且无入场挂单后，守护任务通过真实只读账户快照初始化额度，不需要为了初始化而先开一单。已有状态不可读、账户币种混杂、借贷余额或资金流无法分类时，禁止新风险，不猜测归属。

配置变更在最终入场意图落盘前再次校验签名。核验中配置发生变化会中止本次提交，不盲目重发。既有保证金及并发约束可收紧，但更改初始预算/额度身份需要明确的人工对账与迁移，不自动重置基线。

本轮交付没有创建或启用运行配置；上线与启用应是独立、明确的操作。

## 净值与风控基数
以专属USDT账户为前提，使用余额明细的USDT eq而非折算USD的totalEq，避免币种单位混用：

```text
调整后账户权益 = 交易所USDT权益 - 已完整对账的累计USDT外部资金流
资金池净值 = 初始额度 + (当前调整后账户权益 - 初始化时调整后账户权益)
风控基数 = max(0, min(配置额度上限, 资金池净值, 交易所实际USDT权益))
```

例如模拟账户5000U、额度300U：
- 交易亏损3U后，资金池净值与风控基数为297U，而不是重新给300U。
- 随后入金500U，账户变成5497U，但资金池仍为297U，不能用入金抹掉策略亏损。
- 盈利20U后资金池净值320U，风险基数仍上限300U，不自动复利扩张风险。
- 若提现导致实际账户只剩100U，风控基数最多100U，不创造可交易资金。

日回撤和峰值回撤从资金池盯市净值计算，而不是用5000U大账户稀释300U策略损失。亏损、回撤基线和资金流状态保存在按账户身份隔离的SQLite记录中，重启、临时禁用再启用均不清零。模型费、托管费等不在交易所账户发生的费用不包含在这个账户损益口径中。

## 与现有执行链路衔接
- 先验证决策证据、实际账户、保护单、合约元数据及真实杠杆。
- 同一最终风险网关使用分配后的风控基数、可用额度及单币保证金上限。
- 默认单笔0.5%在300U下为最多1.5U计划风险，仍扣费用/滑点预算、按lotSz向下取整；不足minSz不补足、不扩大风险。
- 现有仓位使用真实imr，挂单按未成交部分和真实杠杆预留保证金；未知不猜测。
- 最后再检查持仓和挂单是否变化，以及额度配置是否变化，再持久化唯一订单意图。
- 资金池阻断仅阻止新增风险，不关闭既有持仓风控、止损或退出逻辑。

## 展示
前台与管理员决策页提供可选资金池卡片，分别显示配置上限、资金池净值、风控基数、交易所USDT权益。不会把真实账户余额覆盖成300U。读取状态不创建额度。`checked_at` 表示只读核验时间，账户余额版本时间单独保留。

## 验证
通过 `scripts/run_tests.py` 在隔离源快照中测试。测试覆盖账户5000/额度300、亏损后重启与入金、回撤、耗尽、实际账户缩水、环境隔离、挂单预留、最小张数、状态损坏、空仓初始化和真实杠杆读取等。

代码及测试通过不等于策略收益已被证明；不要用这个额度功能为未验证的入场机制或高杠杆背书。

账户隔离使用环境与凭证指纹命名空间，不冒充交易所稳定UID。若轮换API Key或切换账户后发现同allocation_id的旧记录，不自动新建300U额度，而要求核对迁移，避免无声清零既有损失。

累计资金流保留追踪起点标识。旧版本回滚、状态丢失等造成起点改变时，不将累计资金流清零解释为策略盈利，而要求对账，阻止新风险。
