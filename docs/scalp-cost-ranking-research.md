# 成本口径、候选择优与影子研究

## 不变的执行边界

本轮不提高盈亏比门槛、不新增WAIT、不增加冷却、不改变开仓频率、杠杆、资金预算、
日内熔断、现有候选的入场/止损/止盈几何。对同样有效输入，候选集合、价格及ID保持不变。
改变的是同一可用候选池中的排序；实际成交仍受既有账户/组合风控和执行情况影响。
不通过延长目标来制造更高盈亏比，也不为新旧规则分别下单。

## execution-costs-v1

共享计算组件提供两种明确标识的场景，单位是每单位基础资产的价格成本，不额外乘杠杆：

- maker_taker_total：Maker入场+Taker退出+滑点+可选点差。保留为原有准入兼容参考，
  不是保证限价单按Maker成交，也不是实际手续费。
- taker_taker_total：双边Taker+滑点+可选点差。用于新排序与程序短线的保守退出保护。

如果把更高的保守费用直接替换进准入门槛，会淘汰部分原候选，故本轮没有暗中这样做。
统一的是计算组件、费率来源及场景标识，不伪装两种使用目的具有相同假设。
波段旧退出及风险预算保留等价计算，不另行改交易行为。资金费与交易手续费分开。
新交易的执行计划保存成本快照；平仓后用交易所实际均价、成交数量及已核对手续费生成
cost_comparison。费用假设落在Maker/Taker区间之外是模型诊断，不改写官方费用或净盈亏。

## scalp-ranking-v1

对原候选全量排序，不设置最低分数、不删候选：

| 因素 | 权重 |
|---|---:|
| 保守成本后的净盈亏比（上限截断，防止远目标支配） | 20% |
| 最近12根5M实际价格范围相对目标距离的覆盖 | 35% |
| 目标空间被估算成本消耗的比例 | 15% |
| 触发1M实体方向质量 | 10% |
| 报价相对触发收盘的追价程度 | 10% |
| 5M均线和收盘方向关系 | 10% |

分数只是启发式优先级，不是胜率预测。高低价格范围是已观测范围，不是预言目标可达。
辅助度量不完整时整池退回旧净盈亏比排序，不把数据缺失变成新增拒单理由。
在相同的账户可用池内同时记录旧排序第一名、新排序第一名、是否改变和实际提交结果。

## scalp-research-v1

分钟循环完成真实提交、释放交易写锁后，用本轮已经取得的公共收盘K线更新独立研究库。
不再发网络请求，不调用模型，不访问交易账户，不写任何订单。研究故障不改变交易结果或重发订单。
研究捕获候选（每帧最多24个，始终保留新旧第一名），并记录捕获截断和实际执行状态。
在既有熔断期间仍可积累影子观察，但熔断不被绕过。

- 15/30/60分钟分别记录目标/止损价是否被观察到，以及观测到的有利/不利价格距离。
- 不假设报价一定成交；入场所在的不完整分钟排除，从下一根完整分钟开始观察。
- 同一根OHLC同时碰到目标和止损，标为ambiguous_same_bar，不假设谁先成交。
- 数据缺口、断线或不完整窗口标为incomplete/unknown_data_gap，缺失不能算失败或盈利。
- 账户隔离、分钟幂等和持久化状态保证重启不重复计样本；未成交影子案例绝不混入真实胜率/账本。

这只是固定候选价格的后续行情观测，不是包含真实成交、滑点、退出管理和资金费的收益回测。
首版不自动修改策略权重或根据影子“胜率”授权交易，需后续人工复盘确认。

## 如何查看

- 账户隔离研究库：data/scalp_research.db。
- 分钟状态：data/demo_scalp_status.json 的 ranking、selection_compare 和 research。
- 认证后的只读汇总：GET /api/v1/cache/scalp-research，使用现有管理员/会话认证。
  新旧排序对照按最近200帧提供，区分已核对的同一账户可用池和仅候选池观察，不把两者混算。
  只汇总有效15/30/60分钟窗口的目标/止损触达，以及明确或有歧义的首次触达；不输出虚构胜率。
- 已平仓账本：execution_cost_model、selection_research、cost_comparison。

观察重点是新旧排序差异、各setup目标距离与实际后续范围、预估和实际费用偏差，
并结合真实净收益核对。不能把影子目标触达率称作策略真实胜率。
