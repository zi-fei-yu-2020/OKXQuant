# 入场机会跟踪与严格 JSON 响应

## 发布边界

`entry-opportunities-v1` 处于影子运行阶段。当前交易执行使用 `closed-candle-plans-v3`，不会自动推广新规则，不改变宏观否决、1.5 ATR 初始止损下限、费用后盈亏比门槛、风险预算、账户模式或订单写入行为。

## 同行情对照

每轮使用已经封存的 15 分钟 / 1 小时 K 线和同一风险契约，对比当前草案与新识别机制：

- 趋势回踩恢复：已有同向 1H 趋势下的回踩回收。
- 区间突破：收盘突破此前 8 根 15 分钟 K 线的区间，量比使用该已收盘 K 线与此前 8 根成交量，不引用可变实时量比。
- 突破后回踩：跟踪最近四根已收盘 K 线内的突破，要求后续收盘未丢失突破位、价格回测后重新确认。追价过远转入等待回踩，不放宽追价阈值。

状态包括观察、等待回踩、影子候选、条件不足、失效、过期。机会有效期一小时；同 ID 的终结状态不能复活，旧 ready 状态不能授权新订单。新结构替代旧结构时明确记录替代；每标的最多保留 60 个跟踪项。账户、执行配置和风险契约隔离，不混用历史状态。

目标按固定顺序选择：触发时已经收盘的小时数据中的最近确认结构拐点；若没有则检查此前 12 根小时线的通道边界。目标必须在入场方向前方。不能为了满足盈亏比继续选择更远目标；缺少可观察目标就明确标记，不通过倍数外推伪造结构证据。回踩验证不引用突破发生之后的小时目标。

## 证据与界面

`strategy_evidence.db` 中 `entry_opportunity_shadow` 保存冻结输入、风险参数和新旧对照；`opportunity_shadow` 保存同账户跟踪状态。即使后续模型 JSON 失败，也保留采集证据。持久化失败不阻塞独立风控，面板对过期对照标记数据延迟。

监控和管理员决策页面在「入场机会对照」中展示现行草案与影子候选，默认收起。主审计行只显示短原因标签；完整理由、引用和复查条件在详情保留。本轮模型失败时，旧审计明确标注为历史，不表示本轮成功。

离线只读对照：

```bash
python scripts/opportunity_replay.py --db /path/to/strategy_evidence.db \
  --scope '<账户范围>' --version '<来源提交完整哈希>' --limit 200
```

此命令不调用模型、不下单、不计算未来收益；未知数据单独统计。接下来需使用未参与规则设计的前向样本评估费用后结果、回撤及保护闭环，不能把候选数增加当作收益验证。

## 严格 JSON 失败处理

- 支持完整 JSON 文本、完整代码围栏、UTF-8 BOM，以及协议明确的文本块数组；不抓取正文中的局部 JSON。
- 拒绝重复键、非有限数、尾逗号、截断 JSON 和供应商声明未完整结束的响应。不补括号、不猜交易字段。
- 解析失败保留错误行列、长度和内容指纹，不向公开接口泄露原文。
- 仅对响应契约问题，允许一次基于原冻结提示词的完整重新生成：最长 20 秒、HTTP 最多一次；不叠加 WAIT 纠错请求。网络失败不增加这里的重试。
- 重新生成只恢复文本解析，不等于交易许可；完整输出仍走原契约、实时价格、有效期、预算和保护核验。失败仍关闭本轮模型指令，不复用旧指令。
- 额外模型调用单独记账，未新增任何下单、撤单或平仓重试。

## 趋势回踩资格与交易标签

执行中的 v3 回踩形态要求同方向的已收盘 1H 均线结构（最近收盘价、7 根均值、20 根均值依次排列）。4H RANGE 仅表示没有完整均线排列，不自动证明价格横盘。单根反弹、负速度减速、聪明钱多头比例不能替代这个前提。

这不是要求所有周期一致：收盘区间突破仍是单独路径，可用于结构恢复研究；模型独立方案不能绕过同向 1H 资格，最终网关再次检查。新草案版本使旧 ID 失效，不修改既有持仓的保护单。

账本不再按方向硬编码“顺势做多 / 阻力高空”。有同账户开仓成交单号、自动下单记录与决策 ID 关联时，回显实际形态；旧 v2 回收形态显示“回收反弹（旧规则）”。缺少直接关联时只显示开多/开空及未关联来源，不推测策略。

## 持仓生命周期与保护日志

本地止损、最高/最低价与持仓时间绑定账户范围、标的、方向、交易所 posId 和 cTime。同标的重新开仓、换账户或旧 tracker 身份未纳管时，旧峰值与止损不能继承；重新核验并采纳当前云端保护，不放宽或重写已有保护。独立风控在确认平仓后清理旧 tracker。

新增云端保护采纳记录，以及独立风控改单前的持久化 pending 状态和意图记录。结果不确定时不重复改单。无法从历史证据确定是谁修改保护单时保留来源未知，不将其归咎于模型、用户或交易所。
