## 标准与 small300 的真实语义

- 策略提示词与执行预设解耦；自定义策略可绑定 standard 或 small300。
- small300 基础预算上限为 300U，但实际数量还受可用 USDT、止损距离、费用、最小合约和持仓占用影响；虚拟额度不是独立交易所钱包。
- 保持已有 horizon 有效单笔比例：scalp 0.4%、swing 0.5%。当可用风险净值是 300U，对应最多 1.2U/1.5U 止损风险预算，而非每单固定保证金。
- 原 small300 描述中的 0.5%/30U/90U/3x 已移除；也不把基础 preset 2%/6x 误称所有路径实际值。页面读取 mode_limits。
- LIVE 分钟策略默认不授权。超级管理员切换并核实 LIVE 账户后，查看当前绑定、输入 ENABLE LIVE SCALP，服务端验证账户/连接版本/策略/执行及政策签名。
- 已授权 LIVE scalp 与 DEMO 使用同一候选、政策和杠杆算法；不自动对既有仓位调杠杆。LIVE swing 不因该授权获得自动调杠杆权限。
- 策略/账户/授权版本改变需新的授权/决策；不得复用旧指令。模拟与实盘实际流动性、手续费等级、撮合、滑点和清算风险不能承诺相同。

## 核心闭环

1. 订单未知与 51603：只读核对、已受理 ordId 找回、pending 终态跟踪、未知请求不盲重发；下单最后边界再次验证授权。
2. 已有仓位：scope+posId+cTime+方向+数量匹配，旧同币同量仓位不能借新生命周期继续授权；退出 tracker 跨重启/策略切换保留原参数。
3. 资金账本：USDT 与 USD 口径分离，标准账户不强加资金池专户条件；生命周期稳定 ID、部分成交、费用未知/null 和旧回执覆盖保护。
4. 模型与信号：同帧跨线程 ContextVar 继承、输出完整性检查、策略版本指纹，损坏新闻不吞掉整轮，营销“宣战”不触发战争熔断，重复报道不滑动延长冻结。
5. 配置：并发写锁、modules 模式不丢失、复制保留源、原子导入、active 快照一致性、执行模式绑定独立保存。
6. 复盘：手动请求持久排队、确认词 RUN EVOLUTION、仅 review 白名单，不推进计划时钟；完成状态补写不重跑模型且 SQLite 非阻塞。
7. 管理：旧写接口权限与新接口一致、错误不泄露凭据、管理500 no-store、公共缓存 scope 隔离、真实任务状态展示。
8. 规则扩展：有限纯数据 AST 解释器取代宿主加载任意 Python，不提供文件/网络/任意函数能力。源码+启用+顺序以配置原子提交生效，data/interceptors 为持久镜像。不是任意 Python 或 OS 安全沙箱。
9. 部署：业务进程 UID 10001、旧命名卷所有权迁移、内置源文件只读；必须在镜像预览验证后上线。
