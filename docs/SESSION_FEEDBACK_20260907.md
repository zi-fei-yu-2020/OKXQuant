# 后台会话失效与短时反馈（2026-09-07）

## 行为

- 后台接口或启动时 `/auth/me` 返回 401：清理失效会话，不再请求退出接口；通过路由 `replace` 自动进入后台登录页，仅显示一次“管理员会话已失效，请重新登录”。
- 会话改变后到达的旧请求结果静默丢弃，不能注销新登录的账号，也不能反复生成页面错误提示。403 权限不足与网络故障不会触发登出。
- 成功、错误、警告、信息通知统一在 3000ms 后移除；重复通知合并，但不延长驻留时间。动画结束可能略晚于计时截止。
- 账户中心原先常驻的错误/结果弹窗改用统一短时通知。输入表单、OAuth 授权步骤、解绑/换号/平仓权限等确认弹窗不自动关闭，不能自动确认。
- 备份上传/下载也接入同一会话校验。离开通知配置页时停止授权轮询，避免已卸载页面继续请求。

## 验证

- 前端 61 项单测（含四类通知的精确时限、重复提示不续期、401/403 分类、旧请求不影响新会话）。
- Windows headed Edge、模拟 API：10 组会话/反馈交互场景，覆盖手机与桌面、会话恢复失败/请求失败、403/500 与确认弹窗保留。
- Windows headed Edge、模拟 API：账户中心、概览、交易标的与持仓、资讯页，390/1440 宽度及亮/暗色共 16 组布局/交互检查，无页面错误或横向溢出。
- 测试未使用真实交易凭据，未发起真实账户写入或交易。

本次只更改前端会话与反馈体验，不调整策略、交易环境、账户绑定或风控规则。
